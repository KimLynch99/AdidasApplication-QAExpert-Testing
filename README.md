# AdidasApplication-QAExpert-Testing
In this repository I will prove my value as a QA Expert tester by testing in all levels the Adidas Application Website.
I am going to run the following tests:

a. Functional Test
b. Responsive Design Test.
c. Regression Test.
d. Negative/Error Handling Test.
e. Usability Test.


I will focus in the following features:

a. Use the searching filter to test if the finding results match the words I entered.
b. Choose a pair of snickers and add them to the cart to see if it updates and save them.
c. In the checkout, enter invalid characters in the email field.
d. Change the browser viewport dimension when adding a product to the cart.
e. Change the browser viewport dimension when trying to process the payment in the checkout.
